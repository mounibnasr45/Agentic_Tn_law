# Removed as vestigial — neither is imported anywhere under app/, eval/ or tests/, and
# neither was even INSTALLED in the environment where the full 165-test suite passes,
# which is what proves they are dead rather than merely unreferenced:
#
#   rank_bm25        - the in-memory BM25Okapi index it provided is gone. The lexical arm
#                      is now Postgres full-text search (tsvector + ts_rank_cd), which is
#                      durable and transactional; that move is what killed bug 1, where a
#                      cold process silently degraded to dense-only because the in-process
#                      index vanished on restart. The name survives only in comments that
#                      explain the old design.
#   duckduckgo-search - a web-search tool from the pre-P5 agent. The current agent has
#                      exactly one tool, rechercher_textes_juridiques, and answering from
#                      the open web is precisely what a citation-grounded legal assistant
#                      must not do.

# Removed with the Angular frontend:
#   streamlit  - replaced by web/, an Angular 22 SPA served by nginx. The UI is no longer
#                a Python dependency at all, so it cannot drift into importing app/.
#
# Removed in P2:
#   chromadb   - replaced by Postgres + pgvector. The lexical arm moved to Postgres FTS
#                and the dense arm to pgvector, so both are now durable. Chroma was the
#                ONLY thing that persisted, which is precisely why a cold process
#                silently degraded to dense-only search (bug 1).
#
# Removed in P1:
#   faiss-cpu     — imported, but its only call site was commented out and no index
#                   file was ever written.
#   requests      — used only by direct_query_openrouter_llm(), which had zero callers.
#   python-dotenv — pydantic-settings reads .env natively; load_dotenv() at import
#                   time was one of the side effects that made config untestable.
